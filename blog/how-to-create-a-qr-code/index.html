What Is a QR Code?

A QR code, short for Quick Response code, is a two-dimensional barcode that stores information in a pattern of black and white squares. Smartphones and QR code scanners can read this pattern to access the encoded information.

Depending on the information stored in it, a QR code can help users open a website, read text, connect to a WiFi network or access contact information.

Quick tip: Always test your generated QR code with a smartphone before sharing or printing it.

Download QR Code in PNG or SVG

After generating your QR code, choosing the appropriate file format is important. QRHub provides PNG and SVG download options.

PNG Format

PNG is a raster image format. It is useful for websites, digital documents, presentations and everyday sharing. Its image quality depends on the exported resolution.

SVG Format

SVG is a vector image format. It can be scaled without the usual pixelation associated with raster images, making it useful for print designs and graphics.

Which format should you choose? PNG is convenient for general digital use, while SVG is often a better choice when you need to resize a QR code for different print sizes. Always test the final exported code.

Tips for Creating Better QR Codes
